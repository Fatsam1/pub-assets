## ✅ الحل بسيط جداً

### خطوة واحدة فقط:

1. **ادخل Zoho Survey:**
   ```
   https://survey.zoho.com
   ```

2. **أنشئ Survey جديد** أو استخدم موجود

3. **اذهب إلى:**
   ```
   Publish → Collect Responses → Email Invites
   ```

4. **انسخ الـ URL:**
   ```
   مثال: https://survey.zoho.com/survey/zs/abc123def456
   ```

5. **احفظها هنا:**
   ```
   E:\work\projects\zoho_sender\invite_url.txt
   ```

6. **شغّل البرنامج:**
   ```bash
   python zoho_sender_gui.py
   ```
