# تثبيت Priv8Agent على Chrome

## الطريقة اليدوية (الأسرع):

1. افتح Chrome
2. اكتب في شريط العنوان: `chrome://extensions`
3. فعّل **Developer mode** (toggle في الأعلى يمين)
4. اضغط **Load unpacked**
5. اختر المجلد: `E:\work\projects\priv8agent-extension`
6. اضغط على الـ extension icon في toolbar واستخدمه

## تشغيل Chrome مع الـ extension تلقائياً:

شغّل `launch-chrome.bat` (في نفس المجلد)
